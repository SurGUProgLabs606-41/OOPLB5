Detailed Description

template<typename T, size_t Capacity>
class RingBuffer< T, Capacity, false >

Специализация буфера для типов, которые нельзя копировать побайтно.

Template Parameters
TТип элементов, для которых нельзя применять побайтовое копирование.
CapacityВместимость буфера.

Если параметр UseMemcpy равен false, используется эта специализация. Использует обычную реализацию getOrderedData из RingBufferCore, копирующую элементы по одному с учетом циклического расположения.
