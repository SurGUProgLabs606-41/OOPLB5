template<typename T, size_t Capacity, bool UseMemcpy>
void printBuffer ( const RingBuffer< T, Capacity, UseMemcpy > & buffer)

Выводит все элементы кольцевого буфера в логическом порядке.

Сначала получает упорядоченную копию данных, затем выводит только фактически занятые позиции. В конце показывает заполненность в формате «количество элементов / вместимость».
