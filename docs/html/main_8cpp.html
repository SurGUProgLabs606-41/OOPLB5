bool loadData ( )

Загружает из data.txt все десять объектов кольцевого буфера.

Каждая непустая строка задает тип, вместимость, количество элементов и сами значения. По первым двум параметрам выбирается подходящий массив и инстанцирование loadBuffer. Проверяются формат строк, поддерживаемые комбинации типа и вместимости, лишние значения и итоговое количество загруженных объектов.

Returns
true, если файл прочитан и загружено ровно десять буферов; false, если файл не открылся или при чтении обнаружена ошибка.
