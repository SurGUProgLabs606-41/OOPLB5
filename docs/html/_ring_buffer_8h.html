Предварительное объявление функции вычисления среднего значения. Для того чтобы далее функция будет объявлена как дружественная к RingBuffer, необходимо предварительное объявление.

Вычисляет среднее арифметическое элементов кольцевого буфера.

Template Parameters

CapacityВместимость буфера.
UseMemcpyПризнак выбранной специализации RingBuffer.
Parameters
bufferКонстантная ссылка на буфер, элементы которого обрабатываются.
Returns
Среднее арифметическое элементов в виде double.

Функция доступна только для арифметических типов. Обходит логические элементы от head с учетом перехода через конец массива. Для вычисления сумма преобразуется к double, чтобы результат не ограничивался целочисленным типом исходных элементов.

Среднее арифметическое всех элементов типа double.

Note
Для std::string функция не подходит; это проверяется через static_assert.

inlinestatic

Хранит общую статистику всех созданных кольцевых буферов.

Переменная используется всеми специализациями RingBufferCore. В ней сохраняется наибольшая вместимость Capacity, встречавшаяся у созданных объектов. Значение не является количеством буферов или элементов.
