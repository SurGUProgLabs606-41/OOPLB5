Detailed Description

template<typename T, size_t Capacity>
class RingBufferCore< T, Capacity >

Реализует основное хранение и операции кольцевого буфера.

Элементы располагаются во внутреннем массиве фиксированного размера. Индекс head указывает на первый логический элемент, а count хранит текущее количество элементов. Когда буфер заполнен, push перезаписывает самый старый элемент и сдвигает head по кругу.

Template Parameters
TТип хранимых элементов. Поддерживаются арифметические типы и std::string.
CapacityФиксированная вместимость буфера; должна быть больше нуля.

Копирует элементы в обычном логическом порядке.

template<typename T, size_t Capacity>
void RingBufferCore< T, Capacity >::push ( const T & value)
inline

Добавляет значение в конец буфера.

Если свободное место есть, значение записывается после последнего элемента. Если буфер заполнен, новое значение заменяет самый старый элемент, после чего head перемещается на следующую позицию по кругу.
