
# RingBuffer

Лабораторная работа №5.
Тема: Шаблонные функции и классы.
Вариант №6: Кольцевой буфер (RingBuffer).

## Описание

Программа реализует шаблонный кольцевой буфер
с фиксированной ёмкостью.

Поддерживаются:
- Добавление и удаление элементов.
- Получение первого и последнего элементов.
- Вычисление среднего арифметического.
- Частичная специализация для тривиально копируемых типов.
- Оптимизация копирования с помощью memcpy.
- Дружественные шаблонные функции.
- Статический учет максимальной ёмкости.

Начальные данные загружаются из файла data/data.txt.

## Структура проекта

- include/ — заголовочные файлы.
- src/ — исходный код.
- data/ — начальные данные.
- build/ — результат компиляции.

## Сборка

make

## Запуск

clang++ -std=c++17 -Wall -Wextra -pedantic -Iinclude src/main.cpp -o build/RingBuffer

## Очистка

make clean

## Требования

- macOS
- Clang
- C++17
- Make
